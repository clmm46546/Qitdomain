Quản lý license

Tạo, tạm khóa, mở lại hoặc xóa mềm license khách hàng.

Đăng nhập quản trị

Nhập LICENSE_ADMIN_TOKEN trong Railway → Variables. Token chỉ được giữ trong bộ nhớ tab này.

Tạo license mới

Key mới — hãy sao chép và gửi cho khách, key đầy đủ chỉ hiện lần này:

Danh sách license

Key chỉ hiển thị 4 ký tự cuối; dùng ghi chú để nhận diện khách.
